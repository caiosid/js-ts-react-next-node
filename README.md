# 📚 Estudos Full Stack: JS, TS, React, Next.js & Node.js

Este repositório foi criado para centralizar e organizar meus estudos, anotações e projetos práticos envolvendo as principais tecnologias do ecossistema JavaScript e TypeScript. O objetivo é registrar minha evolução técnica tanto no Frontend quanto no Backend.

## 🚀 Tecnologias Estudadas

- **Linguagens:** JavaScript (ES6+) & TypeScript
- **Frontend:** React.js & Next.js (App Router / Pages Router)
- **Backend:** Node.js (Express / Fastify)

## 📁 Estrutura do Repositório

O código está organizado da seguinte forma para facilitar a navegação:

- `/backend`: APIs, rotas, integração com bancos de dados e conceitos de Node.js.
- `/frontend`: Aplicações visuais, componentes, gerenciamento de estado e SSR/SSG com Next.js.
- `/exercicios`: Desafios de lógica de programação, algoritmos e fundamentos das linguagens.

## 🛠️ Como Executar os Projetos

Cada subpasta possui suas próprias instruções de execução. De forma geral, o passo a passo padrão é:

1. Clone o repositório:
   ```bash
   git clone https://github.com
   ```
2. Entre na pasta do projeto desejado:
   ```bash
   cd nome-da-pasta
   ```
3. Instale as dependências:
   ```bash
   npm install
   # ou yarn install / pnpm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   # ou npm start
   ```
